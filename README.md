## 零、想直接装到手机上

`课表助手.apk` 是已经编译并签好名的安装包（debug 签名）：

1. 把 APK 传到手机（微信/数据线/网盘都行），点开安装，允许「安装未知应用」
2. 打开 App 就是本周课表；点「导入」进内置浏览器，登录教务系统后点「识别本页课表」
3. 长按桌面空白处 →「卡片」，找到「课表助手」拖到桌面，就是那个 2 列宽、圆角的小组件，点一下直接打开 App

## 一、网页版（现在就能用）

双击 `web\index.html`，或在手机浏览器里打开它。四个标签：

- **课表**：12 节 × 7 天的网格，节次栏固定，今日列有渐变高亮和蓝色时间线，左右滑动看全周
- **今日**：今天每节课的时间、节次、教室、教师、周次
- **导入**：粘贴 JSON / ICS / 课表文字，解析预览后写入
- **更多**：2×3 圆角小组件的真实比例预览、学期设置、载入示例、清空、导出 JSON

数据存在浏览器 localStorage；`更多 → 导出 JSON` 可以把课表导出成文件，用来喂给桌面端或手机 App。

## 二、Android App + 桌面小组件（源码）

`android\` 是一个完整的 Gradle 工程：

- Kotlin，纯 View（没用 Compose），`minSdk 26` / `targetSdk 34`
- **不依赖 androidx**：三个 Activity 直接继承框架的 `android.app.Activity`，主题用系统 `Theme.Material.Light.NoActionBar`，所以这个工程既能用 Android Studio 构建，也能用 aapt2 + kotlinc + d8 手工编译（本机就是这么打出 APK 的）
- 两个桌面组件，都是 `RemoteViews` + Canvas 直接画位图（圆角是位图里 `clipPath` 裁出来的，不是方角白底）：
  - **课表 · 今日**（2×3，圆角 18dp）：第几周星期几 + 当前时间、今天最多 3 节课（色条 + 课名 + 「起始时间 · 教室」），正在上的那节有蓝色圆角底，底部一行「下一节 14:00 大学物理」/「还有 2 节」/「今天没有课」
  - **课表 · 全周**（5×4）：整个星期的迷你网格，今天的列有渐变，带现在时刻的蓝线
  - **点整块卡片任意位置都能打开 App**（`widgetImage` 和 `widgetRoot` 都挂了 PendingIntent）
  - 加组件：桌面长按空白处 → 小部件 → 找「课表助手」→ 把「课表 · 今日」拖到桌面

### 怎么构建

需要 Android Studio（Koala 或更新）+ JDK 17：

1. Android Studio → Open → 选 `D:\课表\手机版\android`
2. 等 Gradle sync 完成（第一次会下载 AGP 8.5.2、Kotlin 1.9.24）
3. 手机连上电脑、打开 USB 调试，点 Run；或者 Build → Build APK(s) 出安装包

命令行也可以（需要有 Android SDK）：

```
cd 手机版\android
gradlew.bat assembleDebug       :: 先执行一次 gradle wrapper 生成脚本
```

如果你机器上没有 `gradlew.bat`，在 Android Studio 里打开一次工程会自动生成；或者用本机已装的 Gradle 8.7+ 执行 `gradle assembleDebug`。

> 说明：这台电脑上没有 Android SDK / Gradle / JDK，也没有外网下载它们，所以 APK 我没法在这里编译验证。工程里刻意避开了 Compose、Glance、KSP、Room 这些对版本敏感的东西，只用经典 View + `RemoteViews`，就是为了在你那边一次 sync 就能过。构建时若提示某个依赖版本找不到，把 `app\build.gradle.kts` 里的 AGP/Kotlin 版本号改成你 AS 提示的版本即可。

### 识别的原理与已适配的教务系统

- **南阳理工（稻星 / 正方系）已适配**：识别 `table#kbxx`（`.personal-course-table`）结构 ——
  表头 `th` 里的「周一…周日」定列、时间列 `.td-course-time` 的 `.course-num` 定节次、
  课程格的 `rowspan` 换算成连堂课（第 1-2 节占两格）、
  同一格里多门课（带红色「冲突」角标）会拆成两张卡并**左右并排**显示。
- 合并格下面那份 `display:none` 的占位格子会被跳过，否则整行会右移一列（这就是"周二跑到周一"那种错位）。
- 学期起始周自动对齐：页面头部有「11周」和「周一 11-16」时，反推第 1 周周一，周次/正在上哪一节都对得上学校。
- 通用兜底：普通 `<table>` 课表（行=节次、列=星期，带 rowspan/colspan）也能认；再不行退回正文文本解析。
### 南阳理工（已内置入口）

导入页第一张卡片自带两个入口：

- **南阳理工 · 教务系统** → https://ngjw.nyist.edu.cn/admin/caslogin，会跳到学校统一身份认证 https://cas.nyist.edu.cn/cas/login
- **网上办事大厅** → https://portal.nyist.edu.cn

登录（学号 + 密码 + 图片验证码）后进「我的课表 / 课表查询」，等表格显示完整，点底部「识别本页课表」。
识别只读当前页面 DOM，不上传任何东西；密码不会被 App 保存。

### 手机上的数据与导入

**主路径：点 App 里的「导入」→ 打开内置浏览器 → 登录教务系统 → 进到课表页 → 点「识别本页课表」。**

- 内置浏览器（WebView）里可以正常登录、翻页，支持 http 站点（很多教务系统还是 http），记住上次打开的网址
- 「识别本页课表」会把 `assets\parse.js` 注入当前页面就地解析：先按 `rowspan/colspan` 还原表格网格，认出「周一..周日」表头列，再逐格提取课程名/教室/教师/周次；表格读不到时用页面正文文字兜底
- 识别出课程后弹出预览（周X 第几节 课程（教室）），可以「替换全部」或「追加」
- 读不到表格的教务系统（图片课表、Canvas 绘制）：用「粘贴文字导入（备用）」，一行一门课，例如 `周一 1-2节 高等数学 教二-105 张三 1-16周`；也可以粘贴 ICS 或从网页版/桌面版导出的 JSON
- 首次启动内置一份示例课表，`学期` 里可以改开学日期和总周数

### 单双周 / 只在某些周上的课

稻星、正方系的课表页面只渲染当前一周，格子里的文字不带周次。所以点「识别本页课表」时，
App 会把学期内每个周次挨个扫一遍（调用页面自带的 `getGrkbInfo({type:1, zc:周次})`，
等 `#kbInfo` 重画完再读），再按「星期 + 课名 + 教室 + 教师」把 16 张表归并成同一门课，
周次取并集，最后压成 `1-16` / `1-4,6-14` / `1-16:odd` / `1-16:even` / `13-14` 这类写法。

相邻节次只有周次完全相同时才并成「第 5-6 节」；周次不同说明是两段不同的安排，会拆成两张卡。

每次写入后还会把课表导出成 `getExternalFilesDir/timetable.json`，
桌面组件右键「从手机同步课表（USB）」就是用 adb 拉这个文件。
（手机 JSON 的 `day` 是 0..6，桌面是 1..7，桌面导入时会 +1。）

### 节次时间

导入时会把教务页面每行的 `time-start` / `time-end` 一起写进 `periods`，
手机的时间列、正在上/下一节提示、小组件时间都基于这套真实时间。
页面只渲染到第 10 节的，第 11-12 节保留默认值。

### 登录失效会发通知

自动更新（课表详情页里的开关）碰到登录态失效时，App 会发一条通知：

- 触发：内置浏览器判断当前停在了登录页（URL 含 `cas/login` / `login` / `sso` / `authservice`，或页面标题含「登录」）且是从「该更新了」进来的
- 通知标题：「课表没更新成功：<官网名字> 登录失效了」
- 点通知 → 直接打开 `WebImportActivity` 并带上那个官网地址，重新登录后点「识别本页课表」就能同步
- 代码：`Notifier.kt`（渠道 `timetable_update`）+ `WebImportActivity.notifyExpired()`

注意：Android 13+ 需要通知权限，首次进入 App 会申请；如果系统里把「课表助手」的通知关掉了，就收不到提醒。

### 小组件是「到点自己动」的

AppWidgetProvider 的 `updatePeriodMillis` 系统最短只给 30 分钟，光靠它刷新，
"上课前 30 分钟切到下一节"最多会晚半小时。所以每次重画完都会算出下一个状态会变的时刻，
用 `AlarmManager.setAndAllowWhileIdle` 精确叫醒自己（不需要精确闹钟权限）：

| 触发时刻 | 会发生什么 |
|---|---|
| 每节课「开始 - 30 分钟」 | 卡片提前切到这门课 |
| 每节课开始 | 文案从「还有 N 分钟上课」变成「正在上」 |
| 每节课结束 | 换成「下一节 …」提醒下一门 |
| 次日 00:05 | 跨天，换「今天」的课表 |

代码：`WidgetScheduler.kt`（算下一个时刻 + 排闹钟）、`widget/WidgetTickReceiver.kt`（收到就重画全部小组件再排下一次）。

### 设置界面：管理 / 切换课表

首页右上角「设置」进 `SettingsActivity`：

| 区域 | 能做什么 |
|---|---|
| 课表列表 | 每行显示「名字 / N 门课 · M 周 · 起始日」；**点一行就切到那份课表**，当前那份有蓝色「当前」标签和蓝边 |
| 长按一行 | 重命名 / 复制一份 / 删除（至少保留一份，删不光） |
| 新建空白课表 | 建一份空表（默认起始日=本周一、16 周、12 节默认时间），建完自动切过去 |
| 复制当前课表 | 把当前这份复制成「xxx 副本」，适合「上学期 / 下学期」各留一份 |
| 学期起始日与总周数 | 改当前这份的 termStart / totalWeeks |

数据都放在 SharedPreferences 的一个「书架」里（`shelf` = `[{id,name,json}]`，`activeId` 记当前），
旧版本只有单份课表的数据会在第一次打开时自动迁移成「我的课表」，不会丢。

切了课表之后首页会自动跳回本周，两天前那份课表的周次不会串到这份上。

### 冲突课：名字竖着排

同一格里有多门课（教务里"冲突"）时，卡片会被分成两/三列。横排文字在这种窄卡里只能挤成两三个字，
所以窄卡改成**一个字一行竖着写**（`GridPainter.drawNameVertical`）：

- 字号按卡的可用高度反算，最低 6.5sp
- 字太多放不下时自动截断并加省略号
- 窄卡里不再画教室（放不下），教室信息照旧在点开详情卡里看

### 课表详情：启用 / 改名 / 官网链接 / 自动更新

设置列表里**点一行**进 `TimetableDetailActivity`（不再直接切换），页面内容：

| 控件 | 说明 |
|---|---|
| 启用这份课表 | 切换当前课表；已是当前时按钮变灰显示「已启用（当前正在用这份）」 |
| 课表名字 | 直接改，保存后设置列表和小组件都跟着变 |
| 官网链接 | 教务系统课表页地址；填了会多出一个「现在去这个网址导入一次」 |
| 自动更新（开关） | 打开后下面才出现两行；关掉就折叠 |
| 官网名字 | 只在自动更新打开时显示，用于首页提示里的称呼 |
| 更新间隔 | 一天 / 两天 / 三天 / 一周 / 半个月 / 一个月 / 半个学期 |
| 上次更新 | 每次成功导入自动记录 |

**关于"自动更新"能做到哪一步**：教务系统是 CAS 登录 + 验证码，App 不能在后台替你输密码，
所以这里做的是「到期提醒 + 一键直达」而不是静默抓取：

- 存下链接、官网名字、间隔、上次更新时间（都在书架 JSON 里，`auto` / `url` / `site` / `intervalDays` / `syncedAt`）
- 超过间隔后，首页底部状态条变成「该更新课表了：<官网名字> 已超过 N 天 · 点这里去更新」
- 点它直接打开内置浏览器（登录态还在，多半不用重登）→ 点「识别本页课表」→ 替换全部 → 自动刷新 `syncedAt`

### 小组件：各种尺寸都能排（四种版式）

桌面给多大的格子，组件就按形状挑版式：

| 形状 | 版式 | 内容 |
|---|---|---|
| 极扁（高 < 60dp，如 6×1） | 单行 | 色条 + `10:10` + 课名 + 教室 |
| 方 / 竖小（如 1×1、2×2） | 迷你 | 课名 + `时间 · 教室` 两行 |
| 常见横条（如 2×1～4×1、2×3） | 卡片 | `10:10 · 第 3-4 节 · 第 11 周` / 课名 / 教室 / 灰字提示 |
| 大块（≥ 96×118dp，如 6×4） | 今日列表 | 表头「第 N 周 · 周X」+ 时钟 + 今天 3–4 门课 |

三个要点：① 所有尺寸按**短边**等比缩放（只按宽度会让 6×4 字号爆掉）；② 卡片版式先量行高，放不下依次丢「提示 → 教室 → 时间」；③ 列表版式一行至少 34dp 才排两行。

### 软件更新（在线检查 + 自动覆盖旧版）

「设置」页最下面的「软件更新」卡：

- 显示 `当前版本 1.1 (2)`；
- **检查更新**：去「更新地址」拉 JSON 比 `versionCode`，有新版本就弹说明 → 带进度条下载 → 下载完自动调起系统安装器 → **覆盖安装、替换旧版**（不会两个图标，课表数据不丢）；
- **更新地址**：填一次记住，支持 `update.json`（推荐）或 `.apk` 直链（直链没有版本号，会先问一句）。

```json
{ "versionCode": 3, "versionName": "1.2",
  "url": "https://example.com/timetable/app-debug.apk",
  "notes": "修了组件尺寸、加了编辑课程" }
```

`url` 必须是**能直下 .apk 的链接**（GitHub Release 的 `/releases/download/...`、raw 直链、自己服务器都行；网盘分享页不行）。

实现（不依赖 androidx / OkHttp）：`UpdateChecker.kt`（HttpURLConnection + org.json + 流式下载带进度）、`UpdateHelper.kt`（版本号 / 安装未知应用权限 / 安装 Intent）、`ApkProvider.kt`（把 cache 里的 APK 透给安装器，绕开 7.0+ 的 `file://`）。

## 三、和桌面版的关系

桌面版（`D:\课表\timetable.ps1`）和手机版用同一份 `timetable.json` 结构，字段完全一样：

```json
{ "termStart": "2026-09-01", "totalWeeks": 16,
  "periods": [{ "no": 1, "start": "08:00", "end": "08:45" }],
  "courses": [{ "name": "高等数学A(一)", "room": "教二-201", "teacher": "张三",
                "day": 0, "start": 1, "end": 2, "weeks": "1-16", "color": 0 }] }
```

`day` 是 0..6（周一到周日），`weeks` 支持 `1-16`、`1-8,10-16`、`1-16:odd`、`1-16:even`。
桌面版导出的 JSON 直接粘到手机 App 的导入页就能用，反过来也一样。

工程里已经放好了 `.github/workflows/android.yml`，它会自动装好 JDK 17 + Gradle 8.7 + Android SDK，编译 debug APK 并作为 artifact 上传。

1. 在 GitHub 上新建一个仓库（私有也行）
2. 把 `android` 目录里的内容推到仓库根目录（`.github`、`app`、`build.gradle.kts`、`settings.gradle.kts`、`gradle.properties` 都要推上去）
3. 打开仓库的 **Actions** 标签，等 `build-apk` 跑完（第一次约 3-5 分钟）
4. 进这次运行的页面，页底 **Artifacts** 里下载「个人课表-debug-apk」，解压得到 `app-debug.apk`
5. 传到手机点安装（需要允许「安装未知来源应用」）

这个方式不用在电脑上装任何东西，只要有网和 GitHub 账号。

### 识别时的进度浮层

点「识别本页课表」后，全周扫描会在页面中间浮一张白卡：

- 标题「正在识别课表」，副标题「正在读取第 N / 19 周…」，下面是蓝色进度条；
- 右上角「取消」，点了会立刻停下（`window.__dshScanCancel`），不会把半截数据写进去；
- 扫完自动关掉浮层，弹出「识别到 N 门课程」的预览。

### 登录失效会发系统通知

更新课表时如果被踢回登录页（URL 命中 `cas/login`、`/login`、`sso`、`authservice`，或标题含「登录」），会发一条系统通知：

- 标题「课表没更新成功：<官网> 登录失效了」，正文「点这里重新登录…」；
- 点通知直接进 App 的内置浏览器停在官网登录页（带 `auto=true`，登录完可直接再识别）；
- 渠道名「课表更新」，id 1001；Android 13+ 需要你在系统里给「课表助手」打开通知权限。
### 自动更新：输官网就行，全自动

你在「课表详情」里填的地址可以只是**学校官网首页**（比如 `https://www.nyist.edu.cn/`），自动更新会自己走完：

1. 打开官网 → 命中「edu.cn 门户」特征，直接映射到教务系统入口（南阳理工：`https://ngjw.nyist.edu.cn/admin/caslogin`）；
   其它学校会退一步：在门户页里找文字含「教务系统 / 综合教务 / 教学管理 / 强智 / URP / 选课」的链接点进去；
2. 进了教务系统（URL 含 `ngjw`、`/admin/`、`jwxt`、`zhjw`、`urp` 之一）→ **自动开始全周扫描**，不用手点「识别本页课表」，进度浮层照样显示；
3. 扫完 → **自动「替换全部」**（不弹预览弹窗），Toast 提示「已自动更新 N 门课程」，然后自己关掉回到课表；
4. 中途被踢回登录页 → 发「登录失效」通知（见上一节），不会把半截数据写进去。

手动导入（自己点「导入」）仍然是老流程：先预览、再选择替换/追加。
### 自动更新在后台跑，通知栏一条静默进度

到期的自动更新不会把界面翻出来打扰你：

- 打开一个 **1×1、透明的导入页**（`silent=true`），界面看不见，扫描照常跑；
- 通知栏出现一条**静默通知**（渠道 `auto_update`，`IMPORTANCE_LOW`、无声无振动、`ongoing`）：
  标题「正在自动更新课表」，下面带细进度条，文字是「正在读取第 N / 19 周…」；
- 扫完自动「替换全部」，通知变「课表已自动更新 / 已更新 41 门课程」，4 秒后自己清掉；
- 撞到登录页会先清掉进度通知，再发「登录失效」通知（见上一节），不会覆盖成一条模糊的提醒。

![静默更新通知](预览-静默更新通知.png)

实现上有个坑值得记：**不能把 WebView 设成 `INVISIBLE`** —— Chromium 会判定页面不可见并节流 JS 定时器，全周扫描会直接卡死（第一次实测就停在「正在读取第 1 / 19 周」不动）。正确做法是只把窗口缩到 1×1、视图保持 `VISIBLE`，另外启动时 `web.resumeTimers()`。

实测：第 10 秒读到「第 9 / 19 周」，第 50 秒落库完成（`shared_prefs/timetable.xml` 时间戳刷新），通知已清除，界面回到课表、没有任何弹窗。
### 自动更新完全在后台（不切界面）

自动更新**不会打开 App 界面**，也不会闪一下黑屏：它跑在 `AutoUpdateService` 里，用一个**没有挂到任何窗口的 WebView** 把教务系统扫一遍。

- 屏幕上不会有任何跳转，你干别的就行；只有通知栏一条静默通知：
  「正在自动更新课表」+ 进度条 +「正在读取第 N / 19 周…」；
- 扫完自动「替换全部」→ 通知变「课表已自动更新 / 已更新 41 门课程」，4 秒后清除；
- 撞到登录页 → 发「登录失效」通知，不写半截数据；
- 全程用 App 已登录的 Cookie，不需要你再登录一次。

实测（`--es demoAuto <官网> --ez demoSilent true`）：

| 时刻 | 状态 |
|---|---|
| +6 s | `topResumedActivity` = Launcher（**从未跳到 App**），`AutoUpdateService` 在跑 |
| +18 s | 通知文字「正在读取第 16 / 19 周…」 |
| +30 s | `shared_prefs/timetable.xml` 刷新、`syncedAt` 更新，通知已清除，Service 已停 |

踩坑记录：**不能把 WebView 设成 `INVISIBLE` 或让它不可见地挂在窗口上** —— Chromium 会判定页面不可见并节流 `setTimeout`，全周扫描会卡死在「第 1 / 19 周」。而**完全不挂窗口**的 WebView 不受这个限制，定时器正常跑，所以后台 Service 这条路才可行。
### 手动添加课程

标题栏「＋」按钮（在「导入」左边）→ 填表保存：

| 字段 | 说明 |
|---|---|
| 课程名 | 必填 |
| 上课地点 | 可空 |
| 上课周数 | `1-16`、`1-8,10-16`、`1,3,5`，结尾加「单」或「双」表示单双周；默认整学期 |
| 星期 / 开始 / 结束 | 下拉选择，默认今天 + 第 1-2 节 |

保存后立刻出现在周视图里（和新课冲突时会自动并排显示），并同步到桌面小组件。加错了可以点开这节课卡片 →「编辑」→「删除」。

![添加课程](预览-添加课程.png)
### 编辑课程（时间 / 地点）

点任意一节课的卡片 → 底部出现「关闭 / 编辑」两个按钮 → 点「编辑」：

- 课程名、上课地点：直接改文字；
- 星期：下拉选周一…周日；
- 开始 / 结束：下拉选第 N 节（开始不能大于结束，会在保存前拦下）；\n- 左下角「删除」：二次确认后删掉这一条（只删当前课表里的这条，重新导入可恢复）。

点「保存」立刻写回当前课表并刷新周视图、状态栏和桌面小组件；点卡片外空白处即可关闭（不会误改）。

![课程卡片](预览-课程卡片.png)

![编辑课程](预览-编辑课程.png)

> 注意：这种改法是**本地改动**，下次「自动更新 / 重新识别课表」会用教务系统的原始数据整体替换，改动会被覆盖。
### 图标

用自适应图标（`mipmap-anydpi-v26/ic_launcher.xml`）：

- `drawable/ic_launcher_background.xml`：满幅品牌蓝 `#0069D9`；
- `drawable/ic_launcher_foreground.xml`：白色课表卡片 + 红黄绿三个圆点，缩到安全区内（0.84）；
- `manifest` 里 `android:icon="@mipmap/ic_launcher"`、`android:roundIcon="@mipmap/ic_launcher_round"`。

这样系统会按自己的形状裁切（ColorOS 是圆角方），图标就不会再出现直角方形。旧的 `drawable/ic_launcher.xml` 保留作兜底，也顺手改成了 24/108 圆角。

## 五、这台电脑上直接打包

- 需要 Android Studio（自带 JDK 17 和 SDK 管理器）：装好后 **Open** 选 `android` 目录，等 sync，然后 Build → Build APK(s)
