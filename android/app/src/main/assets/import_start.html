南阳理工 · 教务系统 网上办事大厅
点上面任意一个，会在本页打开学校登录页；登录后如果能直接看到课表，点最下面的「识别本页课表」。 其它学校就直接在顶部输入框填网址。

登录 → 找课表 → 识别

  1. 用学号密码登录（南阳理工走统一身份认证）。
  2. 进到「我的课表」/「课表查询」页面，等课表完全显示出来。
  3. 点下方的「识别本页课表」，确认课程后写入即可。
识别只发生在你手机本地，课程数据保存在本机，不会上传到任何服务器。

识别不了怎么办

有些教务系统用图片或 Canvas 画课表，程序读不到表格结构。这时有两种办法：
  1. 在课表页长按 → 全选 → 复制，回到 App 点「粘贴文字导入（备用）」。
  2. 或者在电脑上把课表页另存为网页文件，用桌面版组件的「导入教务课表…」处理。
如果一直停在登录页，多半是学校的 http 被拦截或需要 VPN（校园网），换网络再试。
